# Meu Repositório de Aprendizado Git e GitHub

Este repositório foi criado como parte do meu aprendizado sobre Git e GitHub. Aqui registrei minhas práticas para entender melhor o fluxo de trabalho com versionamento de código.

## O que aprendi

- Como criar **commits** para registrar alterações no repositório.
- Como criar uma **branch** para desenvolver novas funcionalidades ou testar alterações sem afetar a branch principal.
- Como **trocar de branch** para alternar entre diferentes linhas de desenvolvimento.
- Como realizar um **merge** para integrar alterações de uma branch para outra.
- Como abrir e gerenciar um **pull request** para revisar e integrar mudanças no repositório principal.
